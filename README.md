# Cpin

Cpin 是 macOS 菜单栏上的剪切板历史工具。复制过的文字、链接和图片会留在里面，按 `⇧⌘V` 找回来，点一下就能接着用。

需要 macOS 13 Ventura 或更新版本，Apple 芯片和 Intel Mac 都支持。

## 安装

1. 拿到 Cpin 的 DMG 后打开它，把 Cpin 拖进“应用程序”文件夹。
2. 在“应用程序”里双击 Cpin。它启动后只出现在菜单栏，不显示 Dock 图标。
3. 如果 macOS 不让打开，先右键点 Cpin 选“打开”。没有这个选项时，到“系统设置 → 隐私与安全性”里点“仍要打开”。

如果第一次打开被 macOS 拦下，多半是因为 Cpin 没有 Apple 的开发者签名和公证。确认安装包来源可信，放行一次之后，同一份应用就能直接打开。没有现成的安装包，可以按文末的说明从源码构建。

## 开始使用

复制一段文字、一个链接或一张图片，按 `⇧⌘V`。面板会出现在鼠标所在的那块屏幕，最新的内容排在最前面。

- 点一下卡片，内容会粘贴回你刚才用的应用。卡片右上角的图钉只负责置顶，不会触发粘贴。
- 同样的内容复制两次，Cpin 只更新原来那张卡片，不会堆出重复项。
- 按 `⌘F` 搜索，内容和来源应用的名字都能搜。
- 常用的片段用图钉钉住，置顶后不计入记录上限。
- 面板可以放在屏幕上、下、左、右，也能在悬浮和贴边之间切换。上下是横排，左右是竖排。
- 想暂时不记录，右键点菜单栏图标，选“暂停记录”。

## 辅助功能权限

直接粘贴要用到“辅助功能”权限。Cpin 需要替你按下 `⌘V`，macOS 得先允许它这么做。

首次启动时，如果没有授权，Cpin 会请求一次，之后不再反复弹窗。也可以打开设置，点“授权直接粘贴…”，系统会跳到“系统设置 → 隐私与安全性 → 辅助功能”，在那里勾选 Cpin。

不想授权也能用：点卡片时 Cpin 会把内容复制到剪切板，收起面板后按 `⌘V`，效果一样。之后想开启直接粘贴，回到 Cpin 就会生效，也可以在设置里点“重新检查授权”，不用重启应用。

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 呼出 / 收起面板 | `⇧⌘V`，或点菜单栏图标 |
| 在卡片间移动 | 横排面板 `←` / `→`，侧边面板 `↑` / `↓` |
| 使用选中的卡片 | `Return` 或 `⌘1`–`⌘9` |
| 搜索 | `⌘F` |
| 收起面板 | `Esc` 或点击面板外；搜索框里有内容时，先清除搜索 |
| 打开设置 | `⌘,` |

点击卡片同样可以直接使用。右键点卡片可以复制、粘贴、置顶或删除。

## 设置

点菜单栏图标后选“偏好设置…”，或按 `⌘,`。可以调整：

- 面板位置（上、下、左、右）和显示模式（悬浮、贴边）。
- 直接粘贴所需的辅助功能权限。
- 记录上限。默认 100 条，可以填任意正整数，也可以勾选“不限制记录条数”。置顶内容不计入；调低上限会删除较早的未置顶记录。
- 暂停记录。
- 存储：查看占用、打开本地数据目录、清空未置顶内容，或删除全部历史、置顶内容和图片。

## 数据与隐私

Cpin 不联网，不用账号，也不上传剪切板内容。所有记录只保存在这台 Mac 上。

数据在 `~/Library/Application Support/Cpin/`，设置里的“打开本地数据目录”可以直接打开。`history.json` 保存文字和卡片信息，`images/` 保存图片；卡片被删除或淘汰时，对应图片也会删掉。

这些文件没有加密。能访问你用户目录的程序或人，都能读到其中的内容。分享出去的 DMG 只包含应用和说明文件，不带你的历史或设置。清空历史不会改动系统剪切板。

密码管理器等应用会主动标记敏感内容，Cpin 会跳过这些条目。不过它认不出所有没做标记的敏感文字，处理密码、验证码时可以先暂停记录。Cpin 启动前和暂停期间复制的内容不会补录。

不会记录的内容：

- 从 Finder 复制的文件
- 富文本格式（只保留纯文字）
- 超过 1 MB 的单条文字
- 超过 16 MB 或 6400 万像素的图片

## 常见问题

**点卡片没有粘贴，只是复制了。**

说明还没有辅助功能权限。到“系统设置 → 隐私与安全性 → 辅助功能”勾选 Cpin，再回设置里点“重新检查授权”。

**按 `⇧⌘V` 没反应。**

快捷键可能被别的应用占用了。点菜单栏图标一样能打开面板。目前不能换快捷键；退出占用它的应用，再从菜单栏退出 Cpin 并重新启动，就会重新注册。

**第一次打开被 macOS 拦下。**

常见提示是“无法验证开发者”或“Apple 无法检查是否包含恶意软件”。Cpin 没有 Apple 的开发者签名和公证。确认安装包来源可信后，按“安装”里的第 3 步放行一次。

**怎么卸载干净？**

退出 Cpin，从“应用程序”删除 Cpin。历史在 `~/Library/Application Support/Cpin/`，偏好设置文件是 `~/Library/Preferences/local.cpin.app.plist`，需要的话一并删除。
